## ADDED Requirements

### Requirement: 展示生成效果预览
系统必须在生成 schema 和代码后展示生成效果预览页，包含组件树、生成效果预览和样式编辑面板。

#### Scenario: 打开生成效果预览
- **WHEN** 用户成功生成布局或骨架屏结果
- **THEN** 系统必须展示组件树、生成效果预览和样式编辑面板

### Requirement: 组件树和预览联动选中
系统必须支持组件树节点和预览元素双向联动选中。

#### Scenario: 点击预览元素
- **WHEN** 用户点击生成效果预览中的元素
- **THEN** 系统必须选中对应 schema 节点，并高亮组件树中的对应节点

#### Scenario: 点击组件树节点
- **WHEN** 用户点击组件树中的节点
- **THEN** 系统必须选中对应预览元素，并使用红色细虚线边框标识该元素

### Requirement: 编辑选中节点样式
系统必须允许用户在样式编辑面板中编辑选中节点的字体、布局、定位、背景和边框样式。

#### Scenario: 修改样式
- **WHEN** 用户修改选中节点的样式字段
- **THEN** 系统必须将修改 patch 到当前前端 schema 的对应 `node.styles`

#### Scenario: 未选中节点
- **WHEN** 没有选中任何节点
- **THEN** 样式编辑面板必须提示用户先选中组件，且不得修改 schema

### Requirement: 保存样式后重新生成代码
系统必须在用户保存样式编辑时，基于当前 schema 和当前代码设置重新调用 `/getCode`。

#### Scenario: 保存样式编辑
- **WHEN** 用户点击保存按钮
- **THEN** 系统必须调用 `/getCode` 并更新当前只读代码文件

### Requirement: 展示只读代码预览
系统必须提供代码预览页，展示只读文件列表、只读代码内容和代码设置抽屉。

#### Scenario: 打开代码预览
- **WHEN** 用户在生成效果预览页点击代码按钮
- **THEN** 系统必须打开代码预览页，并展示当前生成的只读代码文件

#### Scenario: 代码内容只读
- **WHEN** 用户查看代码预览
- **THEN** 系统不得允许用户直接编辑代码内容

### Requirement: 代码设置仅当前会话生效
系统必须让代码设置只在当前页面会话中生效，刷新后恢复默认设置。

#### Scenario: 设置确认
- **WHEN** 用户在代码设置抽屉中确认新的代码设置
- **THEN** 系统必须基于当前 schema 调用 `/getCode` 并更新代码预览

#### Scenario: 页面刷新
- **WHEN** 用户刷新页面
- **THEN** 系统必须恢复默认代码设置，且不得从服务端恢复上次会话设置
