## 需求说明：

> 现在需要开发一个通过视觉稿，基于规则生成代码的应用平台。
>
> client目录写前端应用
>
> server目录写后端服务
>
> 前端UI见UI目录下的图片（图片标题是对应的页面）

## 前端：

### 一、技术栈

React+TypeScript+Vite+AntDesign+less



### 二、功能描述

1. 用户可以上传sketch类型视觉稿，上传成功后把视觉稿展示在视觉稿列表里，用户点击某个视觉稿进入到生成页面。
2. 生成页面里，用iframe展示用户上传的视觉稿，用户可以在选中视觉稿的某一个block，或者用户不选中某个block时，生成整个页面page，点击生成按钮，就会调用后端服务生成代码。
   - 视觉稿列表里含有解压并注入元数据获取逻辑的entryUrl，iframe嵌入的就是该URL
3. 生成代码后弹出预览页，预览页左侧是生成的代码的HTML结构的组件树，中间是效果预览，右侧是编辑面板。
   - 效果预览面板可以点击选中某个元素，选中的元素跟左侧的组件树会联动，选中对应的组件后，组件树的对应组件高亮，预览面板的组件会用红色细虚线的边框表示组件被选中。选中后可以在右侧的编辑面板进行对应的CSS样式编辑，编辑面板主要包括字体、布局、定位、背景、边框这五类样式。
   - 编辑完后可以点击右上角保存按钮，更新生成的代码。
   - 左侧的组件树和右侧的编辑面板可以点击收起按钮后，向左右两边收起。
4. 在效果预览页，点击右上角的代码按钮，可以查看生成的代码。不需要UI图中的对比功能。
   - 代码预览页右上角有个设置按钮，点击设置按钮从右侧滑出设置面板，可以选择要生成的语言类型（HTML、vue、React）、样式命名方式（驼峰、中划线、下划线）、样式类型（css、less、sass）、单位（px、rem、vw、rpx）、导出类型（JavaScript、Typescript）、导出格式（组件、完整项目）、样式引用方式（Inline、Import、Module、Module Style）
   - 设置完全，点击确认按钮后，重新调用接口生成一遍代码，更新代码预览页的代码。
5. 模式选择包含布局模糊（默认）和骨架模式。
   - 布局模式就是正常的生成代码流程
   - 骨架模式就是生成选中block/page的骨架代码





## 服务端：

### 一、技术栈

nodejs+Express

### 二、主要接口

1. 视觉稿上传接口：/upload
   - 用户上传的是.zip压缩文件

1. 根据视觉稿元数据生成schema接口：/getJsonSchema
2. 根据视觉稿元数据生成骨架schema接口：/getSkeletonSchema
3. 根据schema生成代码接口：/getCode
4. 切图接口：/getImage
   - 切图接口用于生成的代码需要用到图片时，例如背景图、icon之类的时候，要调用该接口，根据视觉稿元数据，对视觉指定位置指定宽高的进行切图，生成可用的图片URL
5. 获取视觉稿列表接口：/getSketchList
   - 该包含了视觉稿上传解压完后的index.html的地址entryUrl，创建时间createTime，视觉稿id，视觉稿名称name，视觉稿描述description



>说明：
>
>视觉稿的元数据，在视觉稿上传并解压完后，在服务端通过模板技术把以下逻辑注入到index.html中。
>
>注入逻辑：调用sketch的api —— window.SMApp获取视觉稿artBoard元数据，最终组织好数据，通过postMessage返回组织好后的Page的数据。用户点击视觉稿某个block时，返回组织好后的block数据。

```javascript
// page数据
{
    "layers": artBoard.layers,
    "modLayerId": artBoard.objectID,
    "width": artBoard.width,
    "height": artBoard.height,
    "capture": {
      imagePath: artBoard.imagePath
    }
  };


// block数据
{
    "layers": artBoard.layers,
    "modLayerId": artBoard.objectID,
    "width": artBoard.width,
    "height": artBoard.height,
    "capture": {
      imagePath: artBoard.imagePath
    }
  };

```
