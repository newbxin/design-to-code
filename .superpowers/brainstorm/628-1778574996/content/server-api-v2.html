设计确认 3：服务端接口修订

/getImage 是代码生成过程中的资产裁切能力，由 /getCode 在需要图片资源时使用。

Revised server API responsibilities

Upload & List

POST /upload

GET /getSketchList

POST /deleteSketch

Validate zip, find index.html, inject script, persist only success.

Schema

POST /getJsonSchema

POST /getSkeletonSchema

Receive page/block metadata and return complete schema.

Code

POST /getCode

Receive schema + code options.

When image assets are needed, request crop assets by rect.

Return readonly files array.

Image Crop

POST /getImage

Input: sketch/page image + rect { x, y, width, height }

Crop from full design image and return asset URL.

Generation asset flow

Schema nodes that require image output carry enough source information to identify the full design image and a rect. /getCode calls the crop service, receives image URLs, and emits background-image or img src references.
