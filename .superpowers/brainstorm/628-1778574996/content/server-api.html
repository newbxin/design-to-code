设计确认 3：服务端接口

接口保持少而清楚：上传与资源管理、schema 生成、代码生成、切图。

Server API responsibilities

Upload & List

POST /upload

GET /getSketchList

DELETE /deleteSketch/:id

Validate zip, find index.html, inject script, persist only success.

Schema

POST /getJsonSchema

POST /getSkeletonSchema

Receive page/block metadata and return complete schema.

Code

POST /getCode

Receive schema + code options.

Return readonly files array.

Assets

POST /getImage

Receive sketch id + layer/crop bounds.

Return reusable image URL.

Error behavior

Upload failures return explicit errors and do not create list records. Missing page/block metadata is exposed when the user clicks generate and the schema endpoint cannot be called with valid metadata.
